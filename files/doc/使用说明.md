
config 目录包含开发常用的配置如依赖，构建类型，版本
doc 目录 包含说明/使用文档
script 包含 sh, py 等脚本文件

# config

config.gradle 配置开发常用仓库

config.gradle 中定义了常用的仓库地址，启用配置的仓库地址步骤如下。在顶层的 `build.gradle` 中

```groovy
buildscript {
    apply from : "files/config/config.gradle"
    addRepos(repositories)
}

allprojects {
    addRepos(repositories)
}
```

`build.gradle` 中引用 `config.gradle`

`apply from : config/config.gradle`

引用 `config.gradle` 中的某一项依赖

`implementation project.ext.deps.ui.baserecyclerviewadapter`
